# راهنمای فنی ورود به Tabulae

این مجموعه بر اساس **درخت کاری فعلی** در ۱۵ اکتبر ۲۰۲۶ نوشته شده است. تغییرهای commit نشدهٔ بخش warehouse در تحلیل منظور شده‌اند. هر ادعای مهم با مسیر فایل و، در صورت پایداری، شمارهٔ خط همراه است. «تأییدشده» یعنی در کد یا پیکربندی دیده شده؛ «استنباط» نتیجهٔ منطقی از کد است؛ «نامعلوم» نیازمند مشاهدهٔ محیط اجرایی است. اجرای پایگاه دادهٔ زنده و آزمون backend در این بررسی انجام نشده است.
